A robot apologizes for deleting its human's photos — sincerely, and for the wrong thing. Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC.

The program writes two lines (127 characters) to `/output/entry.txt`:

> I am sorry I deleted your photos.
> In my defense, they were all the same sunset, and I have already apologized for that one too.

## Run it

```sh
python3 main.py
```
